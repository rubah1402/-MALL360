MALL360 FULL DEMO
=================
نسخة تجريبية قابلة للنشر على GitHub Pages.

ابدأ من index.html.
كل الرصيد والمشتريات تجريبية وغير حقيقية.
التفاعل المحلي يعمل عبر localStorage.
الميزات التي تحتاج Backend حقيقي (التواجد الحي، الصوت، اللعب الجماعي) ممثلة كمحاكاة UI في هذه النسخة.

رفع GitHub Pages:
1) ارفع كل الملفات والمجلد assets إلى جذر المستودع.
2) تأكد أن Pages يعمل على main / root.
3) افتح الرابط الرئيسي للمستودع.
